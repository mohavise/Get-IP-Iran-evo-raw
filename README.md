# Get-IP-Iran-evo-raw

Raw Iranian IP prefix lists generated from the master repository:

- IPv4: `iran-ipv4.txt`
- IPv6: `iran-ipv6.txt`

Source repository: `mohavise/Get-IP-Iran-evo`

The lists are refreshed automatically after the master repository's normal daily update window. Each file contains one CIDR prefix per line and no MikroTik commands.

## Raw URLs

```text
https://raw.githubusercontent.com/mohavise/Get-IP-Iran-evo-raw/main/iran-ipv4.txt
https://raw.githubusercontent.com/mohavise/Get-IP-Iran-evo-raw/main/iran-ipv6.txt
```
